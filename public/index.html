Simulador y Entorno Android

Información de Arquitectura:

En Android Nativo: Utiliza UsageStatsManager del sistema operativo para leer eventos de primer plano y un servicio en segundo plano con overlay para bloquear aplicaciones al 100%.

En Navegador Web (Vercel): La API de hardware de Android no está presente en navegadores. Screenly opera con persistencia en localStorage para que todos tus límites, alertas y filtros se guarden de forma real.
